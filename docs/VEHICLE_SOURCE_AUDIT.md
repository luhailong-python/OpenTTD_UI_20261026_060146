## 8方向和实际身体动画

`src/direction_type.h:24–35`定义N、NE、E、SE、S、SW、W、NW＝0–7，方向以屏幕为准：N向视口上方，不是旋转45度的地图北。全图集统一此顺序，不用一张侧视图旋转或镜像冒充八张原生方向。

| 代码 | 实际行为 |
|---|---|
| `src/train_cmd.cpp:509–538` | 方向加image_index得到静帧；载量达到容量一半时使用wagon_full_adder；部分对称车厢原图只用4向，通过方向mask复用 |
| `src/roadveh_cmd.cpp:125–142` | 方向＋基础图像；达到半载阈值时增加roadveh_full_adder |
| `src/ship_cmd.cpp:132–152` | 显示rotation对应8向静帧；双头船可能反转视觉方向 |
| `src/aircraft_cmd.cpp:171–199` | 机身8向静帧；旋翼另外取SPR_ROTOR_STOPPED＋state |
| `src/aircraft_cmd.cpp:106–111, 491–516` | 直升机独立旋翼停止态＋3个旋转相位，不要求机体自己抖动或逐轮动画 |
| `src/effectvehicle.cpp:38–129` | 烟囱烟、蒸汽烟、柴油烟、电火花是分开的效果实体与相位 |

因此上游车身的运输移动主要由游戏在世界空间平移静态朝向图实现。本批交付8向透明身体、适用的空/载外观、旋翼等独立特效及锚点，不捏造无依据的全身摆动、转轮帧或“AI视频”。刚性部件变换和烟效叠加如发生，明确标记派生，而非原生AI运动。

## 制作、尺寸和验收

使用内置image_gen；用户未授权付费API、CLI或视频路线。技能只用于尺寸、导出与QA约束。每次新图前重读F盘AGENTS、统一配置和模型策略，实际附上邮件及组队两图；F盘完全只读。

采用4列×2行八方向母图，固定等距摄像机约30度俯角、无投影地板、真实透明Alpha、无文字。世界逻辑显示菱形为128×64；载具运行画布建议512×512，每家族统一画布和定位，原生图实际尺寸决定裁切，不把母图放大成512原生细节。

每次生成后逐方向检查：朝向、车头/车尾、身份一致、Alpha、边界、地面接触/悬空、统一物理尺度与前后耦合器。任何错误方向保留未通过，不能以相同图重复八次交差。导出每个EngineID的明确文件/图集索引；空/载可共享原画时在映射中说明；不可见部件动画也不凭空添加。

以上为研究时的生产边界。2026-10-26接续结果：27幅家族原画、216朝向、256ID及2720个型号PNG已落盘，旋翼周期、12种公共效果和15种灾难子类型已完整映射。实际交付、模块复用方式、逐图证据和19438项本地检查见[载具效果交付说明](VEHICLE_FX_DELIVERY.md)。用户画面验收待进行；Unity接入与游戏平移、时刻、碰撞和业务逻辑仍不在当前制作阶段。
