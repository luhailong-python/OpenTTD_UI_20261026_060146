# 工具鼠标、选地和地图标记

这是550项世界实体／地块账本之外，经实际读取源码新增核对的交互美术类。功能源提交为 `cb7027538ccd8c4c15a592fc8f43b623b3fdf3f8`。未向功能参考仓库写入、提交或推送，未写F盘，也没有Unity工程或C#代码。

当前232项源码需求均有显式图片、帧序列、SVG或复用合同，并通过本地美术检查。用户美术验收与Unity接入验证仍待后续进行。

本批合计 **468张正式PNG、360份独立SVG**。包含组件和真实派生／几何文件，不等同于468张新原画。72＋5＋19＋12＋114＋10＝232为需求合同数；55为源autorail预留sprite块数，其中当前合法坡表使用50个绝对offset，未使用的50–54不虚构新图片。

原生组件由 `source-art/pointer-overlay-kit.png` 的实际Alpha连通主体切出，保留跨等分格边界的完整部件。指针、小时葫芦、手势、如意角、地图Pin和玉珠均来自此画。禁止标记、菱形和三角框中心的原生Alpha本来就透明；读取RGBA证实后保留，没有因查看器显示隐藏RGB而擅自填底或抠空。

工具鼠标组合实际手绘箭头和已有功能图标／世界小件。轨制、转换、克隆和方向的局部标记属于明确记录的几何或既有箭头变体。功能名称、轨制和提示文案独立于底图，图标共用规则在逐符号绑定中可查。

所有鼠标及动画帧采用相同96×96画布，实际尖端热点为左上坐标 **[9,8]**。此位置在最终缩小／填充后由可见Alpha>128的箭头尖端测出，并逐帧验证；不是靠提示词猜测。用作UI Sprite时对应建议Pivot为[0.09375,0.9166667]。五组源ticks分别为4×8、3×[10,10,29]、3×[10,10,29]、3×[10,10,29]和2×20；图册乘以源码 `gfx_type.h:417` 定义的27ms进行美术预览，接入时仍应核对实际UI调度。

选地PNG画布288×224，锚点[144,144]，逻辑菱形256×128，预留16px边缘，角高步长32px。SVG和PNG使用相同几何坐标与调色角色，端点玉珠来自原生手绘切片。几何、描边、Alpha填充和方向指示是制作工具绘制的功能覆盖层；没有宣称AI原生4K。五角色是neutral、coverage-blue、invalid-red、error-pulse-red和authority-amber。错误脉冲保留独立Alpha关键值说明，当前阶段没有编写游戏业务代码。

交付入口为 `previews/pointers/index.html`，可逐个选择72工具鼠标，在红十字上核对热点，查看5组实际动画。独立资源在 `assets/common/pointers/` 与 `assets/world/overlays/`。PNG按整张使用，保留透明画布和锚点，导入时避免旋转或裁掉透明留白；平台硬件指针限制、缩放、遮挡和排序留待Unity验证。

源码清单见 `POINTER_OVERLAY_REQUIREMENTS.json`，逐项采用与复用见 `POINTER_OVERLAY_BINDINGS.json`。检查记录为 `records/pointer-art-validation.json`（4312项PNG／来源／热点／状态检查通过）、`records/pointer-overlay-validation.json`（232／232）和 `records/pointer-browser-validation.json`（离线8／8）。实际看图及当前图片哈希见 `records/pointer-visual-review.json`。模型／质量未披露字段继续保留null；裁切、缩小、调色和矢量几何均不冒称新生原画。
