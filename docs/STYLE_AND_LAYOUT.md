# 视觉、文案与布局合同

统一风格取自用户指定邮件与组队原图，两图已实际查看并真实作为本轮全部七次AI调用的输入。根AGENTS优先于旧designs索引中失效D盘路径及“邮件缺失”说法。

## 颜色与材质

| 用途 | 色值 | 表现 |
|---|---|---|
| 玉绿标题/操作与选中 | #164F45 | 手绘玉绿板、暖金细边 |
| 正文 | #253D35 | 暖米白纸面上的中文 |
| 次要说明 | #6A766A | 保持清楚对比 |
| 米白反色文字 | #FFF2D1 | 深玉绿底上的标题/选中项 |
| 暖金 | #B78F49 | 分隔线、框边与少量强调 |
| 状态红 | #AE493A | 条件不足、错误与警示 |
| 状态绿 | #267B58 | 正常/完成提示 |

主背景为道家Q版日景运输世界；云纹、如意、葫芦、太极、红穗集中在必要边饰，正文区留白。场景插画、系统图标、货物图标、经理头像均为AI原画；功能地图、统计图、键盘和定位框是数据/交互覆盖层，不是用程序替代原画。

## 字体与动态文字

- 标题：Ma Shan Zheng，通常46px，部分主标题62px；SIL OFL 1.1随包。
- 正文：Noto Sans SC，400字重，通常24–27px；按钮/表头650字重。
- 页签：24px，操作按钮通常26px，辅助文字18–22px。
- 按钮文字居中；金额/统计值按用途右对齐；表格正文左对齐。
- 完整逐页文字内容、色值、字号、字体、对齐及实际文字区域在`docs/layouts/<screen-id>.json`，位置坐标为左上原点像素。
- 原画控件不含动态文本；经理/车辆/货物图标也无文字标签。新闻/故事文字属于独立排版，不烘焙进背景。
- 名称“云途万里（暂名）”、地名、公司名、车型名与数值是当前美术示例。参考机制不随古风命名改成RPG系统。
- 保留£作为源游戏默认示例货币。货物“邮件”是运输货品，与聊天/玩家邮箱不同。

## 画布与布局

目标平台采用桌面横屏、鼠标键盘；基准1920×1080，下一阶段建议Canvas Scaler按宽高共同匹配。该分辨率为排版画布，模型原生图尺寸另记。状态卡960×600展示状态语义、消息和相应操作，不冒充完整运行截图。

通用标题、页签、导航、关闭、正文/列表、详情和操作层级统一。地图/货流、采购、时刻表、分组、经理编辑、涂装、播放器、键盘及各类统计采用专用结构。较长列表滚动/分页、空态和错误状态由清单及状态卡表达，数据与执行逻辑留待接入。

Unity切片边距使用Left, Bottom, Right, Top顺序；不是图像坐标x/y。每页spritePlacements给出控件在设计预览中的像素位置、尺寸和建议Image类型，实际锚点/自适应待接入验证。
