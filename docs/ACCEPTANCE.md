模型入口未披露实际版本与质量，早期7张 UI 母图及后续世界/车辆母图均明确标为未确认；目标配置不能当成实际调用证明。1920画布来自手绘资源与独立文字组合，原生生成尺寸另记，不声称原生1920或4K细节。当前母图证据由独立终检重新核对；不是只沿用旧的7张记录统计。

美术参考中的`qdao_ui_redesign_v5/UI_SPEC.md`当前缺失，已报告并记录，没有恢复旧Git内容。实际执行现存根AGENTS、两张指定主参考及同功能规范。

上游未编译或运行；研究基于实际源码/控件/语言与资源。外部基础图像包不是本源码clone的一部分。本项目已扩展制作独立世界地块、地物、车辆方向、施工状态与适用效果；它们是新风格模块重设计，不是可直接安装到上游的OpenGFX替代包。世界拼装浏览器仅预览图片、几何与状态，未实现交通业务和游戏运行逻辑。
