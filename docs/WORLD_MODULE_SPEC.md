# 世界素材几何与交付合同

本项目功能参考 OpenTTD 提交 `cb7027538ccd8c4c15a592fc8f43b623b3fdf3f8`。这是美术模块合同与后续 Unity 导入建议；没有 Unity 工程、Prefab 或运行时验证。F:\work\image 只读，所有新记录保存在本项目。

## 坐标与尺寸

`src/landscape.h:81` 的 `RemapCoords` 为 `screen.x=(y-x)*2*ZOOM_BASE`、`screen.y=(y+x-z)*ZOOM_BASE`。`src/tile_type.h:15–18` 规定世界方格边长16、高差8。新美术采用相同的2:1等距关系，逻辑菱形128×64、正式地面256×128，正式一级高差32像素；这里的逻辑尺寸是本美术合同，不是改写上游常量。

| 类型 | 正式画布 | 左上原点锚点 | Unity Pivot 建议 |
|---|---|---|---|
| 平地、水面、路轨 | 256×128 | (128,64) | (0.5,0.5) |
| 19坡形 | 256×192 | (128,128) | (0.5,1/3) |
| 建筑、树、设施 | 逐项清单中的画布 | 逐项接地点 | `(anchorX/width,1-anchorY/height)` |
| 车辆 | 车辆清单的统一家族画布 | 车辆合同 | 读取家族清单，不按Alpha每帧重心自动对齐 |
| 特效 | 动画组固定画布 | 动画组固定原点 | 读取动画组清单 |

平地四角 N/E/S/W 为 `(128,0)/(256,64)/(128,128)/(0,64)`。地图X增大朝屏幕左下，Y增大朝右下。路网连接口为四条边的中点 `(64,32)/(192,32)/(192,96)/(64,96)`，不是菱形尖角。

透明padding不增加原生细节。所有裁切、缩小、UV投影、坡变形、换色和拼装逐项标注为派生。正式地面四角逻辑位置保持不变，可在渲染Alpha边界外扩约1.5像素防止Bilinear采样露底；该外扩不是额外占地。不能用整幅场景插画替代地块。

## 坡形与地表

`src/slope_type.h` 的19种有效地形：0–14、23、27、29、30。位1/2/4/8对应W/S/E/N角升一级；位16为陡坡标识，最高角升两级。15表示整格升高一级，应复用平地及更高位置。基础坡素材画布预留64像素顶部抬升空间。

坡形通过真实手绘材料的分三角仿射投影产生，不是19张独立模型原画。复杂基础台、半格平台与挡墙另外分层；本合同的19坡不能代替所有建筑基础和桥台。

材质先按实际原图角点投影为UV，再做对边颜色混合，最后输出菱形。地面密度、随机偏移和材质派生记录在 `assets/world/terrain/manifest.json`；岸沙、雪草、浅水另采用新原生方形材质，保留真实母图尺寸。农田实际0–8阶段采用 `assets/world/terrain/field-stages/manifest.json` 的土壤与独立植株/草捆，19坡上的植物保持竖立，不能用旧16个UV平移/调色当作9阶段。导出数量与原画数量分开。每种材质需检查重复接缝、强纹理重复和浅色Alpha细线；本次3种返修材质另有8×8实际正式像素检查。`records/world-production/terrain-validation.json` 中的RMSE仅是辅助，不能代替看图。

水面使用6张实际绘制的水关键图与4步交叉淡化，24帧、每帧100ms、循环2.4秒。它是固定投影的图像合成动画，不是视频生成或流体模拟。河道、岸边、船闸、水桥另有模块和连通映射，不能用水面循环声称全部水利设施完成。

## 层级与遮挡

建议分地面、路轨/河岸、建筑底座、建筑主体、前景遮挡、架空线/灯具、车辆、特效与选择标记。建筑按逻辑地块锚点排序；高体量建筑需按实际footprint与分片清单处理，不通过扩大一张图的碰撞占地解决遮挡。多格房屋、产业和机场需有源ID与组装关系，单张完整建筑画与可组合地块分片分别统计。

根清单逐项保存PNG、宽高、Alpha、锚点、来源SHA、派生操作与状态。动画另存有序帧、时长、循环方式与固定锚点。方向帧是视角，不是动画时间帧；车辆位置、速度、路径与方向选择由下一阶段引擎负责。

## Unity 初值与待验证项

世界精灵建议Sprite/Single、sRGB开启、Alpha来自输入、Full Rect、Bilinear、无Mip Maps、Wrap Clamp、无旋转打包，分地形/建筑/车辆/FX图集，Padding至少4像素并外扩RGB。不要为世界地面使用UI九宫格。Pixels Per Unit与世界单位映射在接入时统一；建议以256正式像素对应一个地块的等距宽度校准，而非把所有资源硬设相同显示尺寸。

导入后需验证透明边、移动时接缝、像素采样、立体遮挡、铁路/道路接头、船闸水位、动画锚点、车辆方向、场景缩放和目标平台压缩。清单中的Unity状态全部是未验证；本阶段浏览器只是美术拼装/动画预览。
