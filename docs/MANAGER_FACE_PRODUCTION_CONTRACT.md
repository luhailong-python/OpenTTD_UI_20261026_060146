# 经理参数化头像制作合同

功能依据为固定OpenTTD提交`cb7027538ccd8c4c15a592fc8f43b623b3fdf3f8`的`company_face.h`、`company_manager_face.h`与`company_gui.cpp`。实际机器清单是[235条要求](MANAGER_FACE_REQUIREMENTS.json)，不得用8张完整预设胸像代替独立部件。当前来源/裁切配置为`config/manager-customization.json`；只有实际原画落盘、看图并填写真实格序/所有权后才导出正式部件。

使用512×512透明画布，锚点[256,496]。画布是注册规格，不表示原画具有512原生细节。实际部件只做原画裁切、比例缩小、有限坐标重采样、Alpha分层与明确局部调色；禁止扩大母件补足尺寸或代码补画五官。图像工具未披露的原生型号/质量仍由母图生成记录标为未确认；离线导出不能替代该证据。

4个干净正面头/颈基底对应4源码样式；不根据样式标签推断族群名称。每个基底需确实没有将被替换的眉眼、鼻、嘴、发、胡须、眼镜、耳饰和服饰。共同骨架的数值只是初始导向，正式位置以新原画实际测量为准。长发或长胡须用实测发根/嘴部锚点注册，不能为了塞进统一小框缩成错误比例。裁切配置支持真实单元框与`registration.sourceAnchorWithinCellPx / destinationAnchorPx / scale`；scale不得大于1。

下巴采用真实干净基底的互补下颌画件，清除原基底同一区域，防止新旧轮廓双影。有限变形保持上下两行接缝固定，仅改下颌中段宽度，不增加新原画细节。face2第二固定Sprite槽有独立下颌填充，不在此固定槽冒充可选控制。

213个Sprite值槽、16条Toggle与6条Palette共235条绑定均保留`sourceStyle/sourceVarIndex/sourceValue/sourceSpriteId`等源码字段。不同兼容样式可明确共享真实部件；每个可选值至少出现在一张实际组合中，重复组合PNG按像素去重。开启胡须时严格隐藏独立鼻和嘴；胡须绑定本身使用真实鼻/嘴母件加真实胡须构成下半脸，避免缺鼻嘴。关闭眼镜或耳饰只隐藏其层，不用透明空PNG凑数。

眼色仅对实际虹膜掩码内的画件像素换色；保留原画明暗和Alpha，掩码外RGBA须完全相同。皮肤若需匹配，只在该部件的皮肤所有权区域处理；不得连眉毛、瞳孔、衣服或其他层整体换色。基底/五官/服饰每层独立，动态姓名、数值、外观码和业务文字从底图分离。

合成顺序按源码的活动Sprite变量索引递增；高级列表按`uiPosition`排序，两者不能混同。高级、滚动、胡须开启、眼镜关闭、耳饰关闭、三眼色、外观码载入/保存/错误和取消还原等整屏使用现有道家手绘控件，记录实际文字区和控件布局。它们是图片与离线预览，不是Unity运行或配置保存的实现。

美术Sprite建议Single、Full Rect、Bilinear、Clamp、sRGB、保留Alpha；初验关闭有损压缩与Mip Map。mask是数据，不可显示为白色画件，建议关闭sRGB/压缩。全部经理层共享512画布与锚点，不对脸部做九宫格拉伸。全套通过逐图/组合/UI实际看图和机械复核后才报告本地美术验收；用户画面验收与Unity接入另列。
